# 🍽️ GigaEat

> **Хакатон Sber Spring 2026** — фича «Что поесть сегодня?» для приложения **«Худеем на здоровье»**

---

## 💡 Идея

Пользователь нажимает одну кнопку — и получает **персональный рацион** на оставшийся день: завтрак, обед, ужин с учётом того, что уже съел. GigaChat подбирает блюда под КБЖУ и аллергии, находит ближайшие магазины Купера и одним тапом кладёт продукты в корзину.

---

## 🔄 Как это работает

```
Пользователь нажимает «GigaEat»
        ↓
Система читает остаток КБЖУ + уже съеденные блюда
        ↓
GigaChat генерирует рацион (завтрак / обед / ужин + список продуктов)
        ↓
Купер находит 5 ближайших магазинов и ищет каждый ингредиент
        ↓
Пользователь выбирает магазин (доставка или пешком)
        ↓
Корзина сформирована → редирект в Купер для оплаты
        ↓
КБЖУ автоматически списываются из профиля
```

---

## ✨ Ключевые фичи

| Фича | Описание |
|---|---|
| 🧠 **AI-рацион** | GigaChat генерирует персональный рацион под остаток КБЖУ |
| 🥗 **Учёт съеденного** | Система знает что пользователь уже ел сегодня |
| 🚫 **Строгие аллергии** | Аллергены явно запрещены в промпте — никаких исключений |
| 🏪 **Двойной тип магазинов** | Доставка (сортировка по времени) и Пешком (сортировка по расстоянию) |
| 🛒 **Автокорзина** | Продукты автоматически кладутся в Купер |
| 📊 **Гибкий рацион** | 1, 2 или 3 блюда — в зависимости от оставшихся калорий |

## 🛠️ Стек технологий

### Backend
- **Go 1.25** + **Gin** — HTTP-сервер
- **PostgreSQL 15** — основная БД
- **GigaChat API** — генерация рациона (реальный)
- **Купер API** — поиск продуктов и корзина (mock на SQLite)
- **Docker** — контейнеризация

### Frontend
- **React + TypeScript + Vite** — SPA
- **Mobile-first** дизайн под приложение «Худеем»

## 🚀 Быстрый старт

### Backend

```bash
# Клонировать репо
git clone <repo-url>
cd Backend

# Запустить через Docker
docker build -t gigaeat-api .
docker run -p 8080:8080 \
  -e GIGACHAT_TOKEN=<your_token> \
  -e DB_URL=<postgres_url> \
  gigaeat-api

# Mock Купера (отдельный сервис на :8081)
go run ./cmd/mock-kuper/main.go
```

### Frontend

```bash
cd Frontend/GigaEat
npm install
npm run dev
```

## 📡 API

Базовый URL: `http://localhost:8080`

| Метод | Endpoint | Описание |
|---|---|---|
| `GET` | `/health` | Health check |
| `GET` | `/api/v1/profile` | Профиль пользователя (КБЖУ, цели) |
| `PUT` | `/api/v1/profile` | Обновить КБЖУ |
| `POST` | `/api/v1/ration` | **Сгенерировать рацион** |
| `GET` | `/api/v1/ration/:id` | Получить рацион по ID |
| `GET` | `/api/v1/ration/history` | История рационов |
| `POST` | `/api/v1/ration/:id/cart` | Сформировать корзину в магазине |
